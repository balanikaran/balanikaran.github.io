# Security Policy

## Supported Scope

The current `main` branch and the production site at
[karanbalani.tech](https://karanbalani.tech) are supported.

## Reporting a Vulnerability

Please report security issues privately through GitHub's private vulnerability
reporting flow when available. If that is unavailable, email
`karankbalani@gmail.com` with a clear description, reproduction steps, and any
relevant screenshots or logs.

Please do not open public issues for security vulnerabilities.
